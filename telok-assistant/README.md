# Telok AI Team

Личный AI-ассистент и контент-команда для нескольких клиентов. Панель: **http://127.0.0.1:8481/assistant**. Исходная редакция: http://127.0.0.1:8481/.

Можно отправить обычный вопрос, документ или бриф. Для контента команда готовит маркетинговый разбор, три идеи, сценарий со стабильными ID сцен, промпты и проверку пакета. Можно выбрать идею, отдельно изменить сцену, загрузить MP4 и собрать вертикальный ролик. Режим генерации видео выполняет внешние заказы только при явно включённом Seedance и денежных лимитах.

На этом компьютере проверены живые ответы Qwen, полный контент-пакет, точечная правка и настоящий монтаж. ChatGPT Plan, Telegram и Seedance требуют личного подключения; их живой пилот ещё не пройден. Генерация демонстрационного MP4 выполнена локально, без Seedance. [Точный статус](STATUS.md).

## Запуск

Нужны Python 3.12, Docker Desktop и FFmpeg/FFprobe в PATH.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1
```

На текущем компьютере окружение уже установлено. Повторный запуск: `START_TELOK.cmd`. `scripts/stop.ps1` сохраняет данные. PostgreSQL слушает localhost:54391; API — localhost:8481.

## ChatGPT Plan

В панели нажать **Continue with ChatGPT**, лично войти и разрешить приложению доступ. Загрузить модели, выбрать модель, проверить официальные Usage settings и ограничить purchased credits, затем выполнить проверочный запрос. VERIFIED выставляется после завершённого ответа.

Используется отдельный официальный OAuth-сеанс приложения. Credentials текущего Codex не копируются. OpenAI Platform API key для этого маршрута не нужен. Авторизация и доступность функций вашего аккаунта ещё должны пройти живую проверку. Нельзя обещать бесплатную генерацию изображений, видео или транскрипцию за счёт этой подписки.

Маршруты: CHATGPT_ONLY, LOCAL_ONLY, AUTO. AUTO разрешает локальный резерв только при совместимой задаче и определённых ошибках; смена провайдера отображается. Веб-исследование и анализ фото не заменяются текстовой Qwen. Подписочный журнал отделён от USD-ledger; лимит — 12 физических модельных вызовов на задачу. Старый платный API используется только при явно заданном `TELOK_REASONING_PROVIDER=openai_api`, автоматического перехода к нему нет.

## Telegram / TaroForMonkey

Исходники поставки опубликованы в отдельной ветке `telok-assistant`, каталоге `telok-assistant/` репозитория TaroForMonkey. Основная ветка и текущие мемы/таро сохранены.

Для локального запуска ввести токен BotFather и **личный положительный Telegram user ID** в панели. GitHub Actions secrets нельзя прочитать обратно: имеющиеся TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID не извлечены. Chat ID группы не является user ID владельца.

Перед запуском Telok нужно остановить `.github/workflows/chatid.yml` в основной ветке через Actions → workflow → Disable workflow: он читает getUpdates. Два независимых обработчика одного токена мешают друг другу. Рассылки мемов/таро можно сохранить, если они только отправляют сообщения и не читают getUpdates. Ввод настройки требует подтверждения, что старый poller остановлен; никаких workflows автоматически не отключено.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Bot
```

Принимать команды разрешено только владельцу в личном чате. Обычный текст запускает задачу; `/ask`, `/research`, `/content`, `/cancel ID`, `/projects`, `/use ID`. Ответ на сообщение задачи продолжает её в том же проекте. Поддерживаются документы PDF/DOCX/TXT/MD/CSV и фото Telegram. Голосовая транскрипция ещё не подключена.

## Видео

Без видеопровайдера выдаётся PROMPTS_READY. В панели можно импортировать отдельные MP4-сцены и заказать монтаж. Собирается H264/AAC, 720×1280, 24 fps. Совпадающие сцены и исходники повторно используются; изменённая сцена требует актуального клипа.

Seedance 2.5 использует отдельные аккаунт, API key и деньги BytePlus ModelArk. Нужны доступный в вашем кабинете model ID, точные доверенные CDN-домены загрузки, `TELOK_SEEDANCE_CALL_RESERVE_USD`, task/daily budgets и подтверждённый тариф. Встроенный адаптер ограничен целыми длительностями 4–30 секунд, 720p, 9:16. Регион, тариф, фактический доступ и поддержка параметров проверяются на первом малом живом заказе.

Перед HTTP создаются резерв и запись физической попытки. Неизвестный submit не повторяется автоматически; деньги удерживаются до сверки. Статус по известному job ID можно обновить без нового заказа. Отмена Telok не гарантирует отмену заказа/расхода у внешнего провайдера. Ledger без тарифного resolver показывает консервативную оценку, не точный счёт.

Техническая проверка MP4 выполняется над реальным файлом. Отдельная проверка пятью кадрами требует модели с анализом изображений и явно не покрывает весь ролик или звук. Речь, субтитры, детали товара и факты должен проверить владелец. Внешние публикации остаются отдельной операцией с подтверждением версии.

## Секреты и поставка

На Windows runtime credentials защищены DPAPI, записываются атомарно с FileLock. На Linux — локальный файл с правами 0600 в каталоге 0700; DPAPI там отсутствует. `.env`, `.secrets`, assets, логи и runtime results исключены из Git/Docker-контекста. Credentials не входят в экспорт PostgreSQL и backup assets; после восстановления требуется личный вход.

Официальный OAuth в этой версии предназначен для локального приложения. Перенос на постоянный сервер требует отдельной проверки разрешённого размещения и авторизации, сохранения credentials и безопасного локального доступа к настройкам. Готовые Docker-шаблоны не означают, что такой сервер уже развёрнут.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q --timeout 90
.\.venv\Scripts\python.exe -m ruff check telok tests scripts
.\.venv\Scripts\python.exe scripts/check_assistant_ui.py
```

Тесты создают отдельную случайную PostgreSQL database и удаляют только её. Есть проверки OAuth/JWT/refresh, доступа, дедупликации, незавершённого streaming, ограничения локального fallback, UNKNOWN видеозаказа, настоящего монтажа и повторного использования сцен. Тестовые ответы не заменяют живой пилот внешнего сервиса.
