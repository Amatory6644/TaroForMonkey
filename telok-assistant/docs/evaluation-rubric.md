# Pilot качества Telok

На текущий момент известен бренд Telok, его продуктовые характеристики не предоставлены. Fixtures отмечают отсутствие описания; внешний анализ рынка/статистика не выдуманы.

Оценивать реальные материалы по одинаковым briefs, отдельно сравнивая Producer + Reviewer и Ideas/Director + Producer + Reviewer. Демодизайн и детерминированные fixtures не входят в выборку.

| Критерий | Оценка |
|---|---|
| Соответствие задаче | 1–5, с конкретным объяснением |
| Подтверждение фактов | pass/fail; неподтверждённый факт блокирует |
| Соответствие бренду | 1–5 |
| Визуал и читаемость | 1–5; просмотреть настоящий файл |
| Оригинальность | 1–5; сравнить с предыдущими темами |
| Нужные правки | none / minor / major |
| Решение | accept / revise / reject |
| Время редактора | реальные минуты |
| Расход | все физические attempts, включая неудачные/UNKNOWN |

Цена принятого материала = полный расход production/edit attempts этого content item / число принятых итоговых материалов. UNKNOWN cost учитывать как резерв/неопределённый расход, не как ноль. Не считать стоимость только последнего удачного вызова.

Малая выборка помогает найти дефекты и выбрать рабочий процесс, но не доказывает статистическое превосходство. После owner review зафиксировать выбранную цепочку, конкретные дефекты и повторить затронутые cases. Pilot сейчас WAITING_EXTERNAL: нужны описание/факты бренда, AI credentials/limits и оценка владельца.
