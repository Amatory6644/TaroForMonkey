# Отчёты бюджета G-pals тем же Telegram-ботом

Дополнительный локальный обработчик команд для уже существующего бота TaroForMonkey.
Отчёты получает с локального G-pals через HTTP API, а затем отправляет только в привязанный
личный чат. Команды не создают и не изменяют финансовые записи. Для клиента достаточно Python 3.12;
дополнительные пакеты не требуются.

## Где запускается

`src/budget_bot.py` работает на том же ПК, где установлен G-pals. GitHub хранит его код.
GitHub-hosted Actions не видят локальную SQLite-базу домашнего ПК. Публиковать G-pals в интернет
не нужно; по умолчанию адрес — `http://127.0.0.1:8000`.

Карты и мемы из существующих Actions могут отправляться тем же ботом. Только один процесс
может получать его команды через `getUpdates`. В существующем chatid workflow polling отключён;
не включайте его одновременно с локальным клиентом. Если используется Telok или другой получатель
команд, сначала остановите его либо вызывайте `BudgetBot.process(update)` из единого обработчика.
Обнаруженный конфликт завершает клиент. Существующий webhook он не удаляет и чужие сервисы не останавливает.

## Установка и привязка

1. Запустите G-pals с версией, предоставляющей `GET /api/reports/summary`.
2. В **@BotFather → /mybots → существующий бот → API Token** скопируйте токен.
   Не публикуйте его в чате, коде, коммитах или логах. GitHub Actions secrets нельзя прочитать обратно.
3. Создайте локальный `.env` в корне этого репозитория, используя `.env.budget.example` как образец.
   Если `.env` уже есть, добавьте недостающие строки вместо замены файла. Вставьте токен после
   `TELEGRAM_BOT_TOKEN=`. Для начала `GPALS_TELEGRAM_CHAT_ID` можно оставить пустым.
4. В PowerShell из корня репозитория выполните:

```powershell
py -3.12 src/budget_bot.py --pair
```

5. Клиент покажет случайную команду `/connect <код>`. В течение двух минут отправьте её своему
   боту в **личном чате**, не BotFather и не в группу. ID автоматически сохранится в `.env`.
6. Бот подтвердит привязку. Отправьте `/budget`.

Для следующих запусков достаточно:

```powershell
py -3.12 src/budget_bot.py
```

Для предварительного просмотра без токена и без запросов к Telegram:

```powershell
py -3.12 src/budget_bot.py --preview
```

ПК, G-pals и клиент должны работать; для Telegram нужен интернет. Ctrl+C останавливает клиент.
Локальный G-pals продолжает работать независимо от Telegram.

## Команды и сведения в отчёте

- `/budget` и `/month`: текущий месяц.
- `/today`: расходы сегодня и остатки лимитов текущего месяца.
- `/week`: текущая календарная неделя с понедельника и месячные остатки.
- `/report YYYY-MM`: выбранный месяц, например `/report 2026-10`.
- `/help`: справка.

В отчёте — суммы расходов по категориям, общие расходы, учтённые доходы, лимиты и остатки/перерасходы,
период и время получения данных. При отсутствии лимита это указано явно. «Осталось» означает остаток
категорийного лимита, а не банковский баланс.

В Telegram передаются только эти сводные данные. Заметки, описания отдельных покупок, SQLite и backup
не передаются. Чужие пользователи, группы и неизвестные команды игнорируются. Обычный текст не отправляется
языковой модели. Разметка HTML/Markdown для пользовательских названий категорий не включается.

Токен хранится только в локальном `.env`, offset — в `.gpals-local/`; оба исключены из Git.
Сессия G-pals обновляется после восстановления БД/перезапуска. Токены и URL с токеном не выводятся
при сетевых ошибках. Ответы длиннее лимита Telegram разделяются на несколько сообщений.
При неопределённом результате сетевой отправки после повторного подключения возможен повтор отчёта;
финансовые данные от этого не меняются.

## Проверки

```powershell
py -3.12 -m unittest discover -s tests -p test_budget_bot.py
```

Это тесты с подставным Telegram-транспортом, реальные сообщения они не отправляют.
Живая приёмка: привязка личного чата, `/budget`, `/today`, `/report YYYY-MM`, проверка отсутствия ответа
в группе/другому пользователю и понятная ошибка при остановленном G-pals.

Протоколы: [Telegram Bot API](https://core.telegram.org/bots/api), локальный OpenAPI G-pals
на `http://127.0.0.1:8000/openapi.json`.
